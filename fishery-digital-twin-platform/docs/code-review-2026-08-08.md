# 系统审查与修复记录（2026-08-08）

## 已完成

- 清除了当前工作区中的明文 WiFi/API 凭据；固件改用被忽略的 `wifi_secrets.h`。
- 移除了嵌套空 Git 仓库，备份位于工作区 `tmp/`，项目统一由外层仓库管理。
- 真实传感器、演示和离线占位数据均带来源标记；演示接口不再覆盖实时历史。
- 快照请求失败会明确显示断线，不再把离线占位数据标为在线或实时同步。
- 修复电池百分比被随机演示值覆盖、推进目标冒充实测反馈、空值被当作数字 0 等问题。
- 输入增加范围校验；舵机/推进器离线时拒绝活动控制命令，急停仍可下发。
- 命令采用短 TTL 幂等轮询，不再因一次 GET 丢失；设备固件统一携带控制令牌。
- CORS 默认仅允许本机前端；局域网控制和上报要求令牌；AI 增加超时和限流。
- 水质、电池、AI 报告和日志采用原子 JSON 持久化；桌面版写入 Electron 用户数据目录。
- 桌面端验证 3000/5000 端口服务身份，限制外部导航，并启用 asar（运行时单独解包）。
- 地图瓦片失败时使用本地离线底图；日志读取失败会保留旧内容并显示错误。
- 升级到 Next.js 16.3、React 19.2.8，生产依赖审计为 0 漏洞。
- 新增 ESLint、设备状态测试、CI、Node/npm 版本约束及统一忽略规则。
