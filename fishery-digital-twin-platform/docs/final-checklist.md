# 最终检查清单

## 运行检查

- 执行 `npm install` 后无依赖错误。
- 执行 `npm run dev` 后，前端可打开 `http://localhost:3000`。
- 后端可访问 `http://localhost:5000/api/health`。
- 执行 `npm run build` 可以通过。

## 页面检查

- 首页 3D 船模能显示、自动旋转，点击后可拖动、缩放和查看。
- 系统总览能显示核心指标和模块入口。
- 三维孪生能显示船模、任务状态和演示控制反馈。
- 环境监测能点击“数据采集”，曲线动态生成。
- 环境监测中能生成 AI / 本地预测报告。
- 水上执行机构能显示两块控制板和 8 路舵机。
- 航线规划能显示淡蓝色海域和模拟航迹。
- 设备健康能显示电池和设备状态，异常项为红色。
- 操作日志能记录后端、传感器和控制事件。

## 固件检查

- 第一块板烧录 `maker_esp32_pro_servo_temp_01.ino`。
- 第二块板烧录 `maker_esp32_pro_four_servo_02.ino`。
- 两块板的 `DEVICE_ID` 分别为 `servo-quad-01` 和 `servo-quad-02`。
- ESP32 与电脑连接同一个 WiFi。
- 固件里的 `SERVER_HOST` 和 `SERVER_BASE` 指向电脑当前 WLAN IPv4。
- Windows 防火墙允许 TCP 5000 入站。
- 舵机外部供电稳定，不建议只靠 USB 给舵机供电。
- SimpleFOC 推进板第一次测试时不要安装螺旋桨。
- SimpleFOC 推进板确认参数前保持真实电机输出关闭。

## AI 和安全检查

- `apps/backend/.env` 不公开、不截图、不上传。
- DeepSeek 密钥只放在本机 `.env` 中。
- 不配置 DeepSeek 密钥时，本地预测报告仍可演示。
- 比赛现场尽量使用手机热点或专用路由器。
- 不建议把控制接口暴露在公共校园网或陌生 WiFi 中。

## 推荐演示顺序

1. 首页展示“耕海一号”3D 船模。
2. 进入系统总览。
3. 展示三维孪生中心。
4. 进入环境监测，点击“数据采集”，展示动态曲线。
5. 在环境监测中生成 AI 预测报告。
6. 展示水上执行机构，演示舵机控制。
7. 展示航线规划和设备健康。
8. 最后展示操作日志，说明系统闭环。
