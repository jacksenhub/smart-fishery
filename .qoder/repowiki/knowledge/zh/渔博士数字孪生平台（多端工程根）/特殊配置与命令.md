开发入口为 `npm run dev`（同时启动 backend:5000 与 frontend:3000），构建顺序为 `npm run build`（先 `packages/shared`，再 backend/frontend）。桌面打包命令 `npm run desktop:build` 会依次执行 build → `scripts/prepare-desktop.mjs` → `electron-builder --win nsis --x64`，产物输出至 `release/`。首次部署需运行 `npm run setup:devices`（生成 `apps/backend/.env` 及 `firmware/esp32/*/wifi_secrets.h` 中的 Wi-Fi SSID/密码与 `UISYS_API_TOKEN`）和 `npm run setup:network`（通过 `netsh advfirewall` 放行 TCP 5000 / UDP 42110 私有网络规则）。`npm run doctor` 调用 `scripts/preflight.ps1 -Mode runtime` 校验 Node 版本、端口占用、token 一致性、固件密钥与防火墙规则。
